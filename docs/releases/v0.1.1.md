# Asterveil v0.1.1

本版本新增榜单筛选、优化长榜单显示，并适配登录页，同时新增真实姓名模块。提供普通版 Asterveil 和 Asterveil Pro，Pro 版额外支持 Markdown 编辑器的 PDF 导出、上传与提交。

## 更新内容

- **榜单筛选**：模测“查看进度”和“我的榜单”支持按学校、集团校、时年和现在年级多选筛选，显示符合条件的人数，并支持一键清空。筛选保留原站排名。
- **长榜单显示**：单页保留全部符合条件的人员，减少屏幕外内容的布局与绘制开销，保留原站成绩更新、浏览器查找和完整表格下载。
- **登录页适配**：支持主题配色、深浅色模式和手机布局，补齐输入框的无障碍名称及登录按钮的键盘操作。
- **样式整合**：合并重复的页面样式，共用账户页与登录页的表单样式。
- **真实姓名**：默认开启，把形如 `/user/<id>` 的用户名链接显示为真名，鼠标悬停时以原生提示显示毕业信息，如“高中毕业：2026”；`by` 显示“毕业”，`uk` 显示“年份未知”，`jl` 显示“教练”。数据来自 Better-Names-for-7FA4 的用户表，随扩展打包并按用户 ID 匹配，不联网查询；未收录的账号和 `/user/<id>/...` 子页面链接保持原样；只有头像、没有文字的用户名链接同样会补上真名。关闭该模块或总开关会恢复原始用户名、移除补入的文字并移除标注。

## 下载与安装

| 文件 | 用途 |
| --- | --- |
| `Asterveil-0.1.1-chrome.zip` | 普通版，不含 PDF 功能，体积较小 |
| `Asterveil-Pro-0.1.1-chrome.zip` | Pro 版，包含 PDF 功能与所需资源 |
| `SHA256SUMS.txt` | 两个安装包的 SHA-256 校验值 |

1. 下载所需版本的 ZIP 并解压到固定目录。
2. 打开 Chrome 的 `chrome://extensions` 或 Edge 的 `edge://extensions`，开启开发者模式。
3. 选择“加载已解压的扩展程序”，选中包含 `manifest.json` 的目录。
4. 刷新 7FA4 页面，在右下角星芒按钮中调整设置。

已有用户更新时，将新文件更新到原有加载目录，在扩展管理页点击“重新加载”，再刷新网站页面即可，无需卸载原扩展。切换安装实例前可先保存需要的 Markdown 草稿。

## 验证与适用范围

- 目标浏览器为 Chrome / Edge 120+；尚未验证 Firefox。
- 支持 `https://jx.7fa4.cn:8888/` 与 `https://in.7fa4.cn:8888/`，实际内网运行仍待验证。
- 发布流程执行格式与类型检查、自动测试、两版构建，并核对安装包内容、版本、权限、资源和许可证。
- 外站提交解析依赖各站页面结构，发送后请核对目标站的提交记录。

更完整的功能说明见仓库 [README](https://github.com/DestinyleSnowy/Asterveil#readme)。
