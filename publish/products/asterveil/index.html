三步安装

这里提供的是仅插件包。带本地更新器的安装包从 GitHub Releases 获取。

下载并解压

选择普通版或 Pro 的 ZIP，解压到一个固定目录。后续更新会替换这个目录。

加载扩展

打开 chrome://extensions 或 edge://extensions，开启开发者模式，点击“加载已解压的扩展程序”并选择解压目录。

刷新站点

刷新 7FA4 页面后，右下角星芒按钮打开设置。两个入口共用同一份本地设置。

更多细节

以下行为不会修改网站业务数据，只处理页面展示、本地草稿和用户主动触发的操作。

编辑器与公式

编辑器支持标题、表格、代码、任务列表，以及 $…$、$$…$$、\(…\)、\[…\] 和双反斜杠分隔符。按 Ctrl+F 查找、Ctrl+H 聚焦替换框，支持区分大小写、单次/全部替换与撤销。代码中的公式文本保持原样，Markdown 先经 DOMPurify 清理再用非信任模式渲染 KaTeX。

图片、PDF 与提交

普通版可导出白底 PNG；Pro 另可按 A4 分页导出 PDF，并把上传的 PDF 在本地逐页转成图片后预览提交。图片来源支持 HTTP/HTTPS、相对链接和内嵌图片；跨域受限时可授权后由扩展后台读取，单张最大 10 MB。最终通过原站 multipart 表单提交图片，保留题目参数与隐藏字段，不会直接向服务器发送 PDF。

主题、背景与头像

七项配色包含雾蓝、松绿、鸢紫、蔷薇、琥珀、岩灰与自定义。浅色会自动生成满足对比度的文字强调色；显示模式可选浅色、深色或跟随系统。自定义背景只作用于页面底层，导航、卡片和表格保留底色；图片仅在本地裁剪压缩，不会上传。头像替换用本地生成的 SVG 拦截 Gravatar 及镜像请求，七种样式按用户标识稳定生成。

聊天、计划与提交器

/chat 由独立聊天器接管，会话与消息走站点官方接口，每 5 秒刷新当前会话，支持 Markdown 公式与群管理。计划页提供可拖动、可键盘微调的日期目录。工具栏提交器整合 7FA4 Submitter 0.1.13，覆盖洛谷、UOJ、QOJ、Codeforces、AtCoder、vjudge 等站点，发送时只读取当前标签页并向选定 7FA4 入口提交字段，不收集 Cookie。

权限与数据边界

正式包声明 storage、activeTab、scripting、declarativeNetRequest、alarms、nativeMessaging 及提交目标的精确主机权限。没有全站内容脚本、远程代码加载或 jQuery 注入。设置与草稿保存在浏览器本地，卸载扩展会一并删除。
